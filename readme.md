### El Camino de Santiago Route Map

This interactive web map shows a section of El Camino de Santiago, or the Way of Saint James, in Spain. El Camino de Santiago is a historic pilgrimage route that leads to the Cathedral of Santiago de Compostela. The purpose of this map is to show the route and important landmarks that can be found along the way.

The map includes an interactive route and placemarkers that allow users to view the names of different locations along the trail.

### Map Development

This map was created using:

- Leaflet library
- HTML, CSS, and JavaScript
- GeoJSON route and point data
- Esri World Topographic Map basemap
- Interactive Leaflet tooltips

The route was customized using color, line weight, opacity, and dash styling. The map also automatically adjusts its extent to display the complete route.

### Data and Information Sources

Route data was converted to GeoJSON for use in the web map. Background information about El Camino de Santiago was obtained from American Pilgrims on the Camino.
